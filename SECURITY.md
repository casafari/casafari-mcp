# Security

Report a vulnerability, or a key that has been exposed, to platform@casafari.com. Do not open a public issue for it.

This repository holds configuration, skills and examples only. It contains no backend code and no keys. Never commit a key (`cf_sk_...`): keep it in the environment as `CASAFARI_API_KEY` or in an ignored `.env` file. A key that leaked can be revoked in the console at https://platform.casafari.com/console/.

What each plot's text says can be built

Each plot gets one level, from what its own text states, with the quote it rests on. A plot whose text says nothing is never guessed: it is "nothing stated". Claro's plots search shows the first three levels by default; any other level can be switched on.

What you can rely on

  • Every level rests on a quote that appears word for word in the property's text. A quote that is not in the text, or does not say the fact, is dropped.
  • Hand checks on 16 October: in 40 random plots at the default levels every quote was real. After we stopped counting a plot's current use as permission, 25 of 25 re-read “commercial use stated” plots say commercial use is allowed (“Gewerbegrundstück”, “gewerbliche Nutzung … zulässig”).
  • Of the plots whose title says Gewerbegrundstück, Gewerbegebiet, Industriegebiet or Gewerbefläche, 98% are in the default levels.
  • A plot advertised by several agencies appears once; the other agencies are named with it.

What it is not

  • Not a zoning check. The level is what the advertiser writes. A class read from a Flächennutzungsplan is marked as such: it is not binding on the plot.
  • Locations are approximate. No German plot in the data has an exact location, so plots are not matched to zoning maps yet.
  • "Commercial use stated" includes claims such as "suitable for commercial purposes". Read the quote.
  • The data files some plots abroad under German places. A plot whose title or text says it lies in another country is left out, each with the quote that says so.

Questions to start with

What a team usually settles first when it tries the search.

  1. Which Länder or regions matter for this project, and what plot size range?
  2. Do the three default levels match what your project can use? Should "building land, use not stated" (mostly §34 plots) be included for a project?
  3. Is "suitable for commercial purposes" good enough to show, or only a stated class or permit?
  4. Do you need location figures per plot (road access, drive times, population), zoning maps where the Land publishes them, or both?
  5. How will you use it: through the API, an AI assistant (MCP), or the search page at expansion.casafari.com?
